# Belajar HTML — Project

Simple local learning website with a homepage and an introduction page.

Files added/updated:
- `index.html` — new homepage
- `introduction.html` — updated to use `styles.css` and includes a top link back to the homepage
- `styles.css` — shared stylesheet

How to view locally:
1. Open the project folder in your file explorer.
2. Double-click `index.html` to open it in your browser (or open it from your browser with File → Open).
